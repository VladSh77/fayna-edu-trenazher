### 4.1 Виправлення регресії в `extract_article_by_ref` (секція 3, шлях "п. N")
Повернено `_extract_point_paragraph` як основний + `_extract_point(prefer_body=True)` як fallback:
```python
# 3) Пункт: "п. N" / "пункт N" — пункт, нумерований інлайн у <p>
m = re.search(r"п(?:ункт)?\.?\s*([0-9]+)", ref, re.IGNORECASE)
if m:
    title, body = _extract_point_paragraph(html_text, int(m.group(1)))
    if body:
        return title, body
    # Fallback: спробуй покращений витяг з тіла Правил/Інструкції
    title, body = _extract_point(html_text, m.group(1), prefer_body=True)
    if body:
        return title, body
```

### 4.2 КРИТИЧНИЙ ФІКС БАГА РЕГЕКСУ "стаття" (рядок ~429, секція 1)
**БАГ**: регекс `ст(?:атя)?` не матчив повне слово "стаття" (подвійна т: с-т-а-т-т-я), бо очікував "ст"+"атя" = "статя" (одинарна т). Тому `(?:атя)?` матчив порожньо, а `\.?\s*` падав на наступний символ "а". Це впливало на ВСІ ref з повним словом "стаття".

**ФІКС**: змінено `ст(?:атя)?` → `ст(?:атт?я)?`:
```python
# 1) Стаття: "ст. N" / "стаття N"
m = re.search(r"ст(?:атт?я)?\.?\s*([0-9]+(?:\s*-\s*[0-9]+)?)", ref, re.IGNORECASE)
```
